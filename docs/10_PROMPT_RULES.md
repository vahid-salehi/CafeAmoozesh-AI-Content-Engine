# 10 - PROMPT RULES

Version: 1.0

---

# هدف

این سند استاندارد نوشتن Prompt برای تولید مقالات CafeAmoozesh را مشخص می‌کند.

هدف این است که حتی اگر در یک چت جدید یا با یک مدل جدید کار کنیم، خروجی همیشه کیفیت یکسانی داشته باشد.

---

# اصل طلایی

Prompt نباید فقط موضوع مقاله را مشخص کند.

Prompt باید تمام اطلاعات لازم برای تولید یک مقاله Production Ready را در اختیار AI قرار دهد.

---

# SEO Rules

Prompt باید AI را ملزم کند که:

- SEO Title تولید کند.
- Slug تولید کند.
- Meta Description تولید کند.
- Focus Keyword مشخص کند.
- Related Keywords استخراج کند.
- Semantic Keywords را پوشش دهد.
- Entityها را پوشش دهد.

---

# HTML Rules

Prompt باید اعلام کند که:

- Semantic HTML استفاده شود.
- H2 و H3 استاندارد باشند.
- تمام Code Blockها دارای:

<pre class="line-numbers">

باشند.
