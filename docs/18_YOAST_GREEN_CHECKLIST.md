# هدف

این سند تضمین می‌کند که مقاله قبل از انتشار، بیشترین امتیاز ممکن را در Yoast SEO و Readability کسب کند.

هدف فقط سبز شدن چراغ‌ها نیست؛ هدف بهبود واقعی کیفیت محتوا است.

# SEO Checklist

## Focus Keyword

☐ فقط یک Focus Keyword انتخاب شده است.

☐ Focus Keyword در Title وجود دارد.

☐ Focus Keyword در ابتدای مقاله وجود دارد.

☐ Focus Keyword در Meta Description وجود دارد.

☐ Focus Keyword در URL (Slug) وجود دارد.

☐ Focus Keyword در حداقل یک H2 وجود دارد.

☐ Focus Keyword در ALT یکی از تصاویر وجود دارد.

☐ چگالی کلمه کلیدی طبیعی است و از Keyword Stuffing جلوگیری شده است.

# Title

☐ طول مناسب (ترجیحاً 50 تا 60 کاراکتر).

☐ جذاب و قابل کلیک.

☐ شامل Focus Keyword.

---

# Meta Description

☐ بین 120 تا 156 کاراکتر.

☐ شامل Focus Keyword.

☐ دارای CTA یا دعوت به اقدام.

---

# URL

☐ کوتاه.

☐ فقط انگلیسی.

☐ بدون تاریخ.

☐ بدون کاراکتر اضافی.

---

# Heading Structure

☐ فقط یک H1.

☐ پرش Heading وجود ندارد.

☐ H2 و H3 منطقی هستند.

---

# Images

☐ همه تصاویر ALT دارند.

☐ نام فایل انگلیسی است.

☐ حجم تصاویر بهینه است.

☐ فرمت WebP یا PNG مناسب استفاده شده است.

---

# Links

☐ حداقل 3 لینک داخلی.

☐ حداقل 1 لینک خارجی معتبر.

☐ لینک خارجی دارای rel مناسب (مانند `noopener noreferrer`) در صورت باز شدن در تب جدید.

☐ لینک شکسته وجود ندارد.
