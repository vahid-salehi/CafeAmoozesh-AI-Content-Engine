# هدف

این سند استاندارد طراحی تمام Assetهای گرافیکی مقالات CafeAmoozesh را مشخص می‌کند.

هدف، تولید تصاویر یکپارچه، حرفه‌ای، اختصاصی و سازگار با هویت بصری سایت است.
