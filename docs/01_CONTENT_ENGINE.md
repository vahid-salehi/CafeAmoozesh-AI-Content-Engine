# هدف

این سند، موتور اصلی تولید محتوای سایت CafeAmoozesh است.

تمام مقالات سایت باید دقیقاً مطابق قوانین این سند تولید شوند.

هدف این استاندارد تولید مقاله‌هایی است که:

- از نظر فنی دقیق باشند.
- از نظر SEO با استانداردهای روز گوگل سازگار باشند.
- تجربه کاربری مناسبی ایجاد کنند.
- ساختار HTML استاندارد داشته باشند.
- بدون نیاز به بازنویسی منتشر شوند.
- از نظر کیفیت از نتایج صفحه اول گوگل کامل‌تر باشند.

# Definition of Done

یک مقاله فقط زمانی آماده انتشار محسوب می‌شود که:

✅ تمام مفاهیم اصلی پوشش داده شده باشند.

✅ هیچ Entity مهمی حذف نشده باشد.

✅ HTML نهایی آماده انتشار باشد.

✅ تصاویر مشخص شده باشند.

✅ Prompt تمام تصاویر آماده باشد.

✅ لینک‌های داخلی مشخص شده باشند.

✅ لینک خارجی معتبر اضافه شده باشد.

✅ سئو بررسی شده باشد.

✅ Readability بررسی شده باشد.

✅ مقاله نیاز به Patch بعد از انتشار نداشته باشد.
