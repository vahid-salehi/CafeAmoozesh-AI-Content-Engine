## [1.1.0] - Unreleased

### Added

* Blueprint Standard (`docs/22_BLUEPRINT_STANDARD.md`)
* Official Blueprint workflow for all articles
* Mandatory Blueprint approval before article generation
* Standardized 22-section Blueprint structure including:

  * Search Intent
  * Target Audience
  * Prerequisites
  * What You'll Learn
  * Article Structure (H2/H3)
  * Image Planning
  * Image Prompts
  * Tables
  * Code Examples
  * Internal Linking
  * External References
  * FAQ
  * Quiz
  * Interview Questions
  * Exercises
  * Common Mistakes
  * Best Practices
  * Entity SEO
  * Semantic SEO
  * Yoast SEO Plan
  * Article Specifications
  * Definition of Done

### Changed

* AI must generate a complete Blueprint before writing any article.
* AI must wait for user approval before starting article generation.
* Article generation is not allowed if the Blueprint is incomplete.
