# CafeAmoozesh AI Content Engine

> A production-ready AI content engine for creating high-quality Persian programming articles optimized for SEO, Semantic SEO, HTML, and WordPress.

CafeAmoozesh AI Content Engine is a complete documentation system designed to standardize AI-assisted content creation.

The project helps generate articles that are:

- WordPress Ready

- Human Friendly
